# **Digital Time Capsule** 📟

A C++ project that lets users create, store, and unlock digital messages for the future.

## About 📄

A Simple time Capsule Creator that Can:
- Create Capsules.
- Open Capsules.
- Store Capsules.

## Project Structure 🔨

Project Structure is as Follow:

```
main
├── Digital_Time_Capsule.cpp
└── utilities.h
```
